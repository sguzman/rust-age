# 🎨 Iron-oxide project identity

- CSS OKLCH: `oklch(64% 0.17 29)`
- OKLab: `L=0.64, a≈0.1487, b≈0.0824`
- sRGB: `#E05B4C` (converted and rounded from linear RGB)
- Swatch: [`assets/rust-age-color.svg`](../assets/rust-age-color.svg)

Selection uses perceptually uniform OKLCH coordinates, rather than arbitrary RGB/HSL steps. Its red-oxide hue (29°) intentionally distinguishes Rust Age from Posthorn's amber-orange (~63°). The palette is a project identity, not task status. Contrast is supplied by charcoal `#161A1D` and off-white `#F7F4F1` surfaces; do not use red for small body text on white.
